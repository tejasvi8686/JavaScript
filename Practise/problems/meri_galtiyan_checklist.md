# Meri galtiyan: code chalane se pehle ye check karo ✅

## Gullak
- [ ] Answer number hai? To `0` (guna ke liye `1`)
- [ ] Answer string hai? To `""`
- [ ] Answer array hai? To `[]`

## Loop
- [ ] `let i` likha? (`let` mat bhoolna)
- [ ] Aage: `i < arr.length` (bina -1)
- [ ] Peeche: `i = arr.length - 1` se shuru, `i >= 0` tak
- [ ] Function mein naam `arr` hai ya `str`? Wahi likha?

## Loop ke andar
- [ ] Check aur jodne mein `arr[i]` likha, sirf `i` nahi?
- [ ] `push( )` round bracket, `push[ ]` nahi
- [ ] `result = result + ...` mein `=` lagaya?
- [ ] Even check: `% 2 === 0` (pura likha?)

## End
- [ ] `return` gullak ka naam? (function ka naam nahi)
- [ ] `console.log` hata diya?
